# UTI Score

Aplicativo Android nativo para calculadoras de UTI e geracao de justificativa clinica.

## Escores incluidos

- SOFA
- APACHE II
- Glasgow Coma Scale
- CURB-65
- Wells para TEP
- qSOFA
- CHA2DS2-VASc
- HAS-BLED
- Child-Pugh
- TIMI UA/NSTEMI

## Build

```bash
./gradlew assembleDebug
```

O APK de debug e gerado em:

```text
app/build/outputs/apk/debug/app-debug.apk
```
